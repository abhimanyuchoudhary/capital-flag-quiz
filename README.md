# Capital & Flag Quiz

A mobile-first geography quiz: guess capitals and flags. Built for phones, kids, and family play — no login, no API keys.

## Play

Open [the live site](https://abhimanyuchoudhary.github.io/capital-flag-quiz/) (GitHub Pages).

Or run locally:

```bash
python3 -m http.server 8765
```

Then visit `http://127.0.0.1:8765/`.

## What's in v1

- 55 countries with capitals and emoji flags
- Interleaved capital and flag multiple-choice rounds
- Flag picks show flags only (names revealed after you answer)
- Score, streak, and round length 5 / 10 / 15 / 20

## Files

- `index.html` — screens
- `styles.css` — mobile-first UI
- `game.js` — quiz flow
- `data.js` — country data
